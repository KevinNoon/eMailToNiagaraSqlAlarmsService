Client Rule Builder - creates/edits the per-client YAML files under rules/ that MailAlarmBridge uses to match and extract alarms from incoming email. This page only talks to the MailAlarmBridge process running on this machine; it is not reachable from any other host.

1. Load an existing rule, or build a new one below

2. Guided builder

Common keys: estate, site_name, point_name, point_value, alarm_class, alarm_state, message, timestamp, normaltime, offnormaltime, handle. "literal" fields always produce the same value; "regex" fields extract from the email using a named group (?<val>...).
keymodeliteral valueregexsource defaultvalue_map (KEY=value per line)date hints (comma-sep)timezone

3. Review & save

Saving writes the file directly into the running app's rules/ directory. If rules.reload.on.change=true (the default), MailAlarmBridge picks it up on its next poll cycle with no restart needed.
